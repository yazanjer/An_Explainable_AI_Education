# ---------------------------------------------------------------------------
# Dependency ranges chosen to be compatible with Google Colab's preinstalled
# stack, which now ships NumPy 2.x.
#
# An earlier version pinned numpy==1.26.4 exactly. On Colab that DOWNGRADES
# numpy while leaving pyreadstat's compiled extension linked against the NumPy
# 2 ABI, producing:
#     ValueError: numpy.dtype size changed, may indicate binary
#     incompatibility. Expected 96 from C header, got 88 from PyObject
#
# Exact pins are still available for archival reproducibility -- see
# requirements-lock.txt, generated with `pip freeze` from a verified run, and
# results/manifest.json, which records the exact resolved versions used to
# produce every artefact.
# ---------------------------------------------------------------------------
numpy>=2.0,<3        # >=2.0, not >=1.26: pip leaves an existing 1.26 in
                     # place, and pyreadstat wheels are built against the
                     # NumPy 2 ABI. A permissive floor reproduces the bug.
